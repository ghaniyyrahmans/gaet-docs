# Anti-slop audit 001 — 2026-11-25

Mode: AFTER. No source file was changed during this audit.

Scope: the documentation site in this repository, focused on the copy and comments
written in the SEO/content pass, with a visual pass over light mode, dark mode, and
the 390px breakpoint. Rule tiers set priority: Hard Gate = HIGH, Purpose-Gate = MEDIUM,
Quality Locks = LOW.

## Findings

1. **HIGH · R-02** — Three page titles contain an em dash: `src/lib/seo.ts:34`, `:39`, `:55`. Hard ban on the character in agent-written text.

2. **HIGH · R-02** — The OG and Twitter image alt text contains an em dash: `src/routes/+layout.svelte:74`, `:79`. Same hard ban, in metadata that search and social tools read.

3. **HIGH · R-02, R-17** — A sample CLI output line in `src/routes/docs/[...slug]/+page.svelte:435` uses an em dash and a made-up `12.4 MB` payload. The em dash is banned, and the number is presented as output without being a real measurement.

4. **MEDIUM · R-09** — The `About` eyebrow above the H1 `About Gaet and this documentation` in `src/routes/about/+page.svelte:33` repeats the headline and has no function.

5. **LOW · R-15** — The footer CTA `Get started` in `src/routes/+layout.svelte:124` is a generic template label; the destination is the quickstart, so the label can name that action.

6. **LOW · R-15** — `See all commands` in `src/routes/+page.svelte:73` is a generic CTA; the link goes to the CLI reference.

7. **LOW · R-31** — The three-line comment above `pageMeta` in `src/lib/seo.ts:27-31` narrates a style rule and ends in the marketing phrase `value proposition`. Two lines at most, one fact, and no jargon.

8. **LOW · R-38** — `Documentation in progress` in `src/routes/docs/[...slug]/+page.svelte:836` is a placeholder for a branch that the 404 guard makes unreachable. Dead copy promising future content.

9. **LOW · R-05** — The `On this page` aside in `src/routes/docs/[...slug]/+page.svelte:840-851` shows `Overview` and `Related pages` on pages whose headings do not match those labels. Template structure, not the page's content.

10. **HIGH · R-26** — Found during verification, not in the first pass. The search trigger is a real button, but `.search-overlay` was `display: none` outside the 640px media query, so the dialog never opened on desktop. Pre-existing CSS defect.

## Notes held, not findings

- Arrows on CTAs use `↗` for external links and `→` for internal navigation. That is a consistent affordance with a stated purpose, so R-08 passes.
- Dark mode and the 390px breakpoint were opened and inspected. No clipped text, horizontal overflow, or broken layout was visible. R-03 and R-34 pass on those samples.
- Real commands, file paths, and defaults in the docs come from the Gaet repository. No fabricated testimonials, statistics, or compliance claims were found. R-17, R-18, and R-36 pass except for finding 3.
